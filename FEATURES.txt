================================================================
       Password Vault v3.4 — Feature List
       Developer: Eslam Atwa
================================================================


SECURITY
--------
  * Authenticated Encryption (Fernet) — AES-128-CBC for confidentiality plus
    HMAC-SHA256 for integrity; a tampered vault fails to open rather than
    decrypting to garbage
  * PBKDF2HMAC Key Derivation — 480,000 iterations of SHA-256
  * Brute-Force Protection — configurable max attempts (3-15) + lockout
    (15s-5min), escalating with the failure streak. The streak and the
    deadline persist across restarts, so quitting the app does not clear a
    lockout. This guards the login screen only; an attacker holding a copy
    of vault.dat attacks it offline, where the 480,000 KDF iterations are
    the real defence
  * Auto-Lock — vault locks after inactivity (1-30 min or Never)
  * Auto-Clear Clipboard — clears copied passwords after 10-60 seconds (default 30s)
  * Atomic File Saves — prevents data corruption on crash
  * Key Released On Lock — the master key and decrypted vault are dropped on
    lock. Python strings are immutable, so the bytes cannot be overwritten
    in place; the copies are reclaimed by the GC, not erased on demand
  * Restrictive File Permissions — vault files are owner-only access
  * Master Password Validation — minimum 12 chars, uppercase, lowercase and
    digits, and a strength score of Strong or better
  * Constant-Time Comparison — prevents timing attacks on master password
  * Input Sanitization — SSH/RDP inputs sanitized to prevent command injection
  * Single Instance Lock — one running copy only, so two windows cannot
    overwrite each other's vault
  * Security Dashboard — vault score plus weak, reused and stale password lists
  * Breach Check — Have I Been Pwned lookup by hash prefix only; no password
    or full hash ever leaves the machine
  * Encrypted Backup & Restore — separately-encrypted backup file, restorable
    even from the login screen without the old master password
  * No Recovery Without It — the master password is never stored, so nothing
    can reset it. The app says so once, when the vault is created, and
    offers to make a backup there and then
  * Consistent Restore — a failed restore puts the previous salt back, so the
    vault always stays openable
  * Safe Export — CSV/Excel cells are escaped against formula injection
  * Link Guard — only http and https URLs are opened
  * Lock Hygiene — auto-lock closes every open dialog, leaving no plaintext
    on screen
  * Master Password Change — re-encrypts the vault and rotates the salt.
    The target salt is journalled first, so an interrupted change cannot
    leave a vault that no password opens


USER INTERFACE
--------------
  * Light & Dark Themes — full iOS-inspired palettes, switchable in Settings,
    or set to System to follow the Windows setting
  * English & Arabic — switchable in Settings. Arabic mirrors the whole
    layout: the sidebar, every label anchor and every padding pair flip to
    read right-to-left. The window is rebuilt when the language changes
  * Card Color Customization — 9 color presets (Blue, Green, Red, Orange, Purple, Teal, Yellow, Pink)
  * Default Card Color — set a default in Settings for all new entries
  * Password Strength Meter — real-time visual indicator (Very Weak -> Very Strong)
  * Tooltips — hover descriptions on all buttons and features
  * Category Emoji Icons — automatic emoji per category (Social, Work, Banking, etc.)
  * Show/Hide Password — toggle visibility on login and in edit dialog
  * Fixed-Width Masking — a hidden password's width says nothing about its length


KEYBOARD
--------
  * Ctrl+N — new password        Ctrl+F — focus search
  * Ctrl+L — lock vault          Ctrl+E / Ctrl+I — export / import
  * Enter — submit the focused dialog
  * Esc — close a dialog, or clear the search box
  * Shortcuts and Ctrl+C/V/X/A match the physical key, so they keep working
    under a non-Latin keyboard layout (Arabic, Russian, etc.)


PASSWORD MANAGEMENT
-------------------
  * Password Generator — cryptographically secure, customizable:
      - Length: 6-40 characters
      - Toggle: uppercase, lowercase, digits, special characters
      - Real-time strength preview
      - Defaults configurable from Settings
  * Categories — organize entries into custom groups (General, Social, Work, Banking, Gaming...)
  * Search & Filter — instant search with category filter dropdown
  * One-Click Copy — copy username or password to clipboard instantly
  * Notes — add optional notes to any entry
  * Edit & Delete — full CRUD with confirmation dialogs
  * Duplicate Password Detection — real-time warning if a password is reused
  * Recycle Bin — deleted entries kept for recovery for 30 days, then
    purged from the encrypted file itself, not just from the view


RIGHT-CLICK CONTEXT MENU
-------------------------
  * Available on every entry card (main vault + Mini Vault):
      - Copy Username / Copy Password
      - Open URL in Browser
      - Open URL + Copy Username (the password is NOT auto-copied — use
        Copy Password when you are ready to paste it)
      - Start SSH Session (PuTTY / MobaXterm / Windows SSH)
      - Start RDP Session (mstsc)
      - Edit Entry
      - Pin / Unpin Entry
      - Delete Entry


SSH & RDP INTEGRATION
---------------------
  * SSH Session Dialog:
      - Host/IP input (auto-filled from entry URL)
      - Username (auto-filled from entry)
      - Port selection (auto-detected from URL)
      - SSH Client chooser — auto-detects MobaXterm, PuTTY and Windows
        OpenSSH, in that order, so MobaXterm is what Enter picks
      - Password auto-copied to clipboard on connect and held for at least
        60 seconds, which is longer than a client takes to cold-start and
        ask for it
      - The username and host are passed through exactly as typed. A value
        carrying a shell metacharacter is refused with a message naming it,
        rather than being quietly rewritten
  * RDP Session Dialog:
      - Host/IP input (auto-filled from entry URL)
      - Port configuration. There is no username field: mstsc takes no
        username on its command line, so Windows asks for it itself
      - Password auto-copied to clipboard on connect and held for at least
        60 seconds, ready to paste into the Windows credential prompt


FLOATING WIDGET & MINI VAULT
-----------------------------
  * Floating Widget — minimizes to a small draggable bubble (always on top)
  * Mini Vault — compact always-on-top window for quick access:
      - Category filtering
      - Copy username/password
      - Edit entries directly
      - Full right-click context menu (SSH/RDP/Copy/Edit)
  * Start Minimized — launch directly to floating widget (configurable)


SETTINGS
--------
  * Full iOS-style settings page with persistent configuration:
      - Auto-Lock Timer: 1, 2, 5, 10, 15, 30 min or Never
      - Max Login Attempts: 3, 5, 10, or 15
      - Lockout Duration: 15 sec, 30 sec, 1 min, 2 min, or 5 min
      - Clear Clipboard: Off, or 10, 15, 30, 60 sec
      - Default Password Length: 6-40 characters
      - Character Types: Uppercase / Lowercase / Digits / Symbols
      - Theme: System, Light, or Dark
      - Language: English or Arabic (العربية)
      - Default Card Color
      - Start Minimized option
  * All settings saved to %APPDATA%\PasswordVault\settings.json
  * Validated on load — a wrong type or out-of-range value falls back to the
    default instead of breaking startup


IMPORT & EXPORT
---------------
  * Export to CSV or Excel (XLSX)
  * Import from CSV or Excel, with a preview and a skip-duplicates option
  * Import from other password managers — Chrome/Edge, Bitwarden, LastPass,
    1Password, KeePass and Firefox. The format is detected from the header
    row and shown in the dialog, with a dropdown to override it
  * Bitwarden JSON — read directly rather than as columns, so folders,
    multiple URIs per item, custom fields, and secure notes/cards/identities
    all survive the import
  * Nothing is dropped in silence — TOTP secrets and custom fields are kept
    in the entry's notes, and any column with no home is named in the dialog
    before you import
  * Round-trips categories, URLs, notes, timestamps and pinned state
  * Exported cells are escaped against spreadsheet formula injection
  * Data stays encrypted at rest — export is plaintext (use with care)
  * Encrypted Backup — for a copy that stays encrypted, use Encrypted Backup
    instead of CSV/Excel export


INSTALLER
---------
  * One-click Windows installer (Inno Setup)
  * Supports system-wide or per-user installation
  * Desktop + Start Menu shortcuts
  * Smart Update — detects existing installation, shows version upgrade info
  * Passwords & settings safe during update (stored in %APPDATA%)


DATA STORAGE
------------
  * vault.dat    — encrypted password database (%APPDATA%\PasswordVault\)
  * vault.salt   — encryption salt, 32-byte (%APPDATA%\PasswordVault\)
  * vault.salt.pending — only while a master-password change is in flight
  * settings.json — user preferences (%APPDATA%\PasswordVault\)
  * vault.log    — application event log (%APPDATA%\PasswordVault\)
